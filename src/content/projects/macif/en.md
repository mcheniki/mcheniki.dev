MACIF, an insurance company, needed additional development capacity for several microsites, including a retirement guide.
A design system and a WordPress theme foundation were already in place, using ACF for content blocks. The challenge was to create new reusable blocks while providing a smooth back-office editing experience.

Within a team of three developers, I mainly worked on the shared layer: the parent theme containing blocks used across all child themes.
I designed and built those blocks in PHP/ACF for rendering and React for the editor, following the design system and adding a React layer to overcome ACF limitations and deliver a more Gutenberg-friendly back-office experience.
As the team was newly adopting WordPress, I also contributed as a specialist to identifying and resolving performance and deployment issues related to this new stack.
