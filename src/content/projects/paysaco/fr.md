Paysaco est un site de prestation de services pour l'entretien de haies. La cliente avait besoin de synchroniser les données de commandes entre sa boutique WooCommerce et son CRM externe pour centraliser le suivi client.

J'ai développé de zéro un plugin WordPress en PHP pour synchroniser automatiquement les commandes WooCommerce avec le CRM. Lorsque la cliente a migré vers Salesforce, j'ai conçu une seconde version adaptée à sa nouvelle API. J'ai mené le développement back-end en autonomie, en coordination avec le chef de projet de l'agence.
